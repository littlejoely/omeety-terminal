怎么用
  1. 装好本地 host（macOS：installer/install.sh；Windows：installer/install.ps1）。
  2. 这里就是个真终端，敲 claude / codex / kimi 即可；它们已自动连上浏览器工具。
  3. 在 agent 里说"描述当前网页"→ 它会读取你当前 Chrome/Edge 标签页。
  4. 快捷键：Ctrl+F 搜索输出 · Ctrl+点击 开链接 · Ctrl+滚轮 调字号 · Ctrl+Alt+T/W/←/→ 新建/关闭/切换终端 tab。
  5. tab 标题会随 shell 自动改名（PowerShell/bash 的标题命令）；右键 tab 可手动重命名，手动后不再被自动覆盖。
