# Omeety Terminal v0.1.2 — browser intelligence and lifecycle / 浏览器智能与会话优化

This release gives CLI agents a denser, verifiable view of the current page
while keeping multi-terminal workflows responsive and session recovery reliable
on lower-memory Macs and Windows PCs.

本版本同时增强 Agent 对当前页面的理解与操作验证能力，降低多终端 Tab 的 GPU/内存
占用，并完善侧栏关闭、重新打开和空闲回收时的会话生命周期，适合 8GB 内存的 Mac
与 Windows 设备。

## Highlights / 主要变化

- Only the active terminal tab retains a WebGL renderer; inactive tabs keep
  their PTY state and output buffer without retaining GPU rendering resources.
- Context Bundle v1 combines target semantics, styles, nearby controls,
  iframe/Shadow DOM context, diagnostics, and a cropped MCP image.
- `omeety_act_and_verify` executes an action and verifies explicit page
  postconditions across reloads and navigation.
- Light snapshots support unchanged/delta responses, and runtime metrics report
  tool latency, failures, connection state, and replay-buffer usage.
- Reopening the side panel restores every PTY session that is still alive,
  including titles and per-tab punctuation compatibility.
- Settings now provides 3,000 / 5,000 / 10,000 / 20,000 scrollback lines and
  three close policies: always keep, reclaim after 30 minutes, or end now.
- Host logs rotate as three capped 20 MB files and skip heartbeat plus
  high-frequency dynamic-title metadata traffic.
- Long content pasted with Cmd+V, Ctrl+V, Shift+Insert, or right-click is
  delivered as one terminal Paste event, allowing Codex to collapse it.
- PTYs no longer inherit an accidental `NO_COLOR` value from the browser
  launcher and explicitly advertise xterm-256color plus True Color support.
- The supported smoke suite has a 30-second hard timeout and cleans up its
  Host/PTY on success, failure, interruption, and timeout.

## Verification / 验证

- Browser-free Native Messaging + PTY + MCP smoke suite: 13 checks.
- Context lab: Shadow DOM, same-origin iframe, incremental snapshot, compound wait.
- MCP image content extraction keeps JSON compatibility while exposing real images.
- Real isolated Chrome + Native Messaging + MCP regression covers strict CSP,
  image-bearing Context Bundles, cross-navigation action verification, and metrics.
- Six real xterm tabs: exactly one WebGL renderer, five suspended renderers.
- Thirty rapid tab switches with no page errors.
- Continuous Codex-style synchronized output while switching tabs.
- Cmd+V and right-click each deliver one long bracketed-paste event.
- A Host started with `NO_COLOR=1` still creates a color-capable Omeety PTY.
- Forced test timeout leaves zero child Host processes.
