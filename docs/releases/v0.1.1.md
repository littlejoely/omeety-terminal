# Omeety Terminal v0.1.1 — macOS Chrome support / macOS Chrome 支持

This patch release adds a verified macOS path while preserving all Windows
features from v0.1.0. Omeety remains a real local terminal in the Chrome/Edge
side panel with 28 browser-control MCP tools for Codex, Claude Code, Kimi Code,
and other MCP-capable CLIs.

本补丁版本在保留 v0.1.0 全部 Windows 功能的基础上，新增经过真机验证的 macOS
支持。Omeety 仍然是 Chrome/Edge 侧栏里的真实本地终端，并为 Codex、Claude
Code、Kimi Code 等 MCP CLI 提供 28 个浏览器控制工具。

## macOS support / macOS 支持

- Google Chrome side panel with a real zsh PTY, verified on macOS.
- System default Shell plus zsh, bash, fish, and custom executable selection.
- User-level Native Messaging registration for Chrome, Edge, and Chromium.
- Automatic MCP configuration for Codex CLI, Claude Code, and Kimi Code.
- Homebrew and common CLI locations added to the terminal PATH.
- Automatic repair for the `node-pty` macOS `spawn-helper` executable bit.

## Install / 安装

### macOS

1. Download and extract `omeety-terminal-v0.1.1-macos.zip`.
2. Install Node.js LTS.
3. In macOS Terminal or iTerm, run `./installer/install.sh`.
4. If macOS asks whether `node` may use Developer Tools, choose **Allow**.
5. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**,
   and select the extracted `extension` directory.

下载并解压 macOS 包，安装 Node.js LTS，在系统 Terminal 或 iTerm 中运行
`./installer/install.sh`。如果系统询问是否允许 `node` 使用开发者工具，请选择
“允许”。随后到 `chrome://extensions` 开启开发者模式并加载 `extension` 文件夹。

### Windows

Download `omeety-terminal-v0.1.1-windows.zip`, extract it, and run:

```powershell
powershell -ExecutionPolicy Bypass -File installer\install.ps1
```

## Compatibility / 兼容性

- Verified: Windows 11 + Microsoft Edge; macOS + Google Chrome.
- Chrome and Edge use the same Chromium extension code.
- Safari is not included. A Safari port requires a containing macOS app and a
  separate adapter for Side Panel, Native Messaging, and CDP-dependent tools.
